# LuckyApe
Lucky Ape 🐒 | Smart Probability, Bananas Results.  Stop picking birthdays! Lucky Ape scrapes real-time results from The Lott Australia to generate data-backed lotto combinations using hot frequencies, overdue cold numbers, and odd-even models.
